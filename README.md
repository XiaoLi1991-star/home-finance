# Home Finance

一个面向家庭和个人使用的资产台账 App。

它不是记账软件的完整替代品，更像一本放在手机里的「家庭资产簿」：把银行卡、现金、基金、房贷、借款、长期资产这些信息放在一起，定期确认一次，看看家庭资产是在变稳、变松，还是需要多留意。

## 适合谁

- 想定期看清家庭净资产的人
- 想把资产和负债放在同一张表里管理的人
- 不想把私密财务数据交给在线服务的人
- 想用 AI 帮忙整理月报，但希望密钥和数据尽量留在本机的人

## 主要功能

- 记录资产和负债：现金、存款、投资、房产、贷款等都可以放进台账。
- 月度确认：每个月更新一次关键金额，形成快照，方便回看变化。
- 资产概览：查看总资产、总负债、净资产、负债率和资产健康度。
- 洞察页面：按分类查看结构，也可以查看资产负债走势。
- AI 月报：可选接入自己的模型接口，生成更容易阅读的家庭资产月报。
- 图片月报：把月报生成适合保存和分享的图片卡片。
- 隐私模式：隐藏金额、比例等敏感数字，适合截图或当面查看时使用。
- 本地备份：可以导出新版备份文件，方便自己留存。

## 隐私说明

这个 App 的设计重点是「本地优先」。

- 台账数据保存在本机。
- AI 访问密钥使用 Android 原生安全存储保存。
- 备份文件需要你手动导出。
- 如果你启用 AI 月报，请确认你选择的模型服务是否适合处理个人财务信息。

开源仓库里不会包含你的 API key、keystore、APK 构建产物或个人数据。

## 安装

可以在 GitHub Releases 里下载 APK。

目前提供的是 debug APK，适合自用和小范围试用。安装时 Android 可能会提示「未知来源」或「调试版本」，这是正常现象。

如果你已经安装过旧版本，直接覆盖安装通常可以保留本机数据。为了稳妥，升级前建议先在设置里导出一次备份。

## 使用建议

第一次使用时，可以先做三件事：

1. 在设置里补充出生年份和家庭年收入，用于资产健康度估算。
2. 在台账里录入当前有效的资产和负债。
3. 到月度页面做一次确认，生成第一份家庭资产快照。

之后每个月只需要更新一次关键金额，App 就能帮你保留变化轨迹。

## 重要提醒

本项目主要用于个人和家庭资产整理，不构成投资、理财、税务或法律建议。所有评分和 AI 月报都只能作为辅助参考，真正的财务决策仍需要你自己判断。
